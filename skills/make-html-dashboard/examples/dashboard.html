01Overview

This is the base dashboard template: a two-pane shell, KPI cards, inline SVG charts, a station table, and an optional chat panel. Replace the dummy values in data/dummy-data.json.

Base template. The shell, tables, charts, print styles, Aa appearance panel, and chat launcher are all wired. Keep the template files intact and only swap the payload.

Dummy payload

Every value comes from data/dummy-data.json; nothing is fetched at build time.

Self-contained output

The builder inlines the CSS, inline SVG charts, and widget JavaScript into one HTML file.

Optional features

Chat, histogram, zone bars, overview copy, station note, and colophon are opt-in fields in the payload.
